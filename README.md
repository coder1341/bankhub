# 🏦 BankHub

BankHub is a modern digital banking web application built with Django. It provides users with a secure platform to create accounts, manage profiles, view account information, and perform basic banking operations through a clean and responsive interface.

## ✨ Features

- User Registration & Login
- Secure Authentication
- User Dashboard
- Profile Management
- Profile Picture Upload
- Account Number Generation
- Deposit, Withdrawal & Transfer Pages
- Transaction History
- Responsive Mobile-Friendly Design
- PostgreSQL Database Support

## 🛠️ Built With

- Python
- Django
- HTML
- CSS
- JavaScript
- PostgreSQL
- Render

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/coder1341/bankhub.git
cd bankhub
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run migrations:

```bash
python manage.py migrate
```

Start the server:

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000
```
